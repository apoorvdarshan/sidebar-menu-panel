# 📸 Sliding Sidebar Panel – CSS Only

This mini project is a simple and responsive **sidebar navigation panel** built using just **HTML** and **CSS** — no JavaScript involved. Inspired by a photography storefront layout.

---

## 🔍 Features

- ✅ Smooth sliding sidebar
- ✅ Pure CSS transitions (no JavaScript)
- ✅ Responsive design
- ✅ Minimal, clean UI
- ✅ Ideal for beginner-level frontend practice
